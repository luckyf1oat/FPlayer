## 4. 反控（逐条可判 False；缺原始输出即判未验）

1. **作用域**：起窗后打印"参与取数的服务器 = [<主源>]（长度 1）"；**反控 = 临时把 `LastServerId` 指到另一台已启用服务器** ⇒ 屏上卡片应整体换成那台的收藏（条数/标题随之变），证明"只查主源"而不是"恰好只有一台有数据"。
2. **三类型**：逐类型查询计数（`Movie`/`Series`/`Episode`）与复合查询计数须满足"三者之和 = 复合"，且**三个分区同时存在**；**反控 = 故意把类型集合缩回 `"Series,Season"`** ⇒ 断言必须变 False（证明断言真的盯着这件事）。
3. **聚合口径一致**：打印收藏屏与聚合视界收藏过滤器使用的**同一个常量值**；**反控 = 只改其中一处** ⇒ 断言变 False。
4. **缓存不回归**：重跑 `t54` 的四条反控（冷启动 / 打断网热路径退化 / 坏源缓存仍在 / 两 id 集合分别打印）+ `⑤` 就地替换（实例身份）+ `⑥` 起播门一负一正，**全部须仍为 True**。
5. **起窗存活**：`favorites` 与**一个别的落点**（反控，如 `library`）各起一次，报 pid + 起止时刻 + 进程存活；**证据落到独立临时目录**（`SHELL_EVIDENCE_DIR`），避免重写库内被引用证据造成 `H5` 过期身份。
